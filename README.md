# Worksheet

점 모눈종이 무한 캔버스 위에 **워크박스**를 놓고, 서로 **연결**하고, 숫자 박스로 **간단한 계산**까지 하는 데스크톱 워크시트 프로그램입니다.
정보 정리, 스토리 구상, 가계부, 플래너 등 어디에나 쓸 수 있습니다.

## 실행 (Windows 포터블)

1. `Worksheet-0.2.0-portable.exe` 를 원하는 폴더(USB 도 가능)에 둡니다.
2. 더블클릭해서 실행합니다. 설치 과정은 없습니다.
3. 만든 워크시트와 설정은 실행 파일 옆 `WorksheetData` 폴더에 저장됩니다 (`WorksheetData/Worksheets` 가 내 워크시트 모음). 폴더째 옮기면 그대로 이어서 쓸 수 있습니다.

> 코드 서명이 없는 프로그램이라 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다.
> **추가 정보 → 실행** 을 누르면 열립니다.

## 기능

### 0.2.0 에서 새로 바뀐 것

- **자동 저장 + 내 워크시트 모음**: 새로 만들면 바로 파일이 생기고, 고칠 때마다 자동으로 저장됩니다. 시작 화면에 미리보기 그림과 함께 최근 순서로 모이고, 이름 바꾸기 · 사본 · 휴지통 · 폴더에서 보기 · 찾기가 됩니다. 위쪽 막대의 이름을 고치면 파일 이름도 바뀝니다
- **새 디자인**: Pretendard 글꼴, 아래쪽에 떠 있는 도구 막대, 고른 박스 바로 위의 **빠른 편집 막대**(색 · 모양 · 글자 크기 · 굵게 · 정렬 · 형식 · 묶기 · 복제 · 삭제), 필요할 때만 여는 속성 패널(`Ctrl+.`)
- **빨리 쓰기**: 글을 쓰다가 `Tab` 을 누르면 오른쪽에 연결된 새 박스, `Ctrl+Enter` 는 아래에 같은 모양의 새 박스. 생각을 끊지 않고 마인드맵 · 목록을 이어 쓸 수 있습니다. 워크박스를 그리면 바로 글을 쓸 수 있습니다
- **찾기 · 목차** (`Ctrl+F`): 글로 박스를 찾아 그 자리로 이동, 비워 두면 워크박스와 큰 제목이 목차로
- **묶기** (`Ctrl+G` / `Ctrl+Shift+G`): 고른 박스들을 워크박스로 감싸기 / 풀기
- **첫 줄을 제목으로**: 워크박스 하나에 제목(굵게)과 내용을 함께 쓰는 카드
- **내보내기**: 전체 또는 고른 박스만 PNG(2배 선명도) / PDF(한 장) 로
- **링크**: 글 속의 `https://…` 를 `Ctrl` + 클릭하면 브라우저로 열기
- **터치패드 모드**: 설정 → 캔버스에서 휠을 '화면 이동'으로 (두 손가락으로 이동, `Ctrl`+휠로 확대). 휠 모드에서는 `Shift`+휠로 가로 이동
- **간격 맞추기**: 박스 3개 이상을 가로/세로로 같은 간격으로
- **큰 이미지 자동 줄이기**: 넣는 사진의 긴 변을 1600px 로 줄여 파일이 무거워지지 않게
- **템플릿**: 할 일 보드, 계정 장부(예시) 추가, 기존 템플릿도 글을 바로 쓴 워크박스로 새로 구성

### 전체 기능

- **무한 캔버스**: 휠로 확대/축소(5% ~ 800%, 끝에 가까울수록 천천히), Space+끌기로 화면 이동, 종이처럼 배율에 따라 함께 커지고 작아지는 점
- **테마**: 밝은 테마 / 어두운 테마(어두운 회색 + 옅은 하늘색). 위쪽 해/달 버튼이나 보기 메뉴에서 바꾸고, 다음 실행에도 유지
- **설정 창**: 위쪽 톱니바퀴(`Ctrl+,`). 화면 · 캔버스 · 마우스 조작 · 단축키 · 계산(수식) · 정보를 항목별로 따로 보여 줌
- **워크박스**: 사각형 · 둥근 사각형 · 원 · 마름모. 더블클릭해서 글을 쓰고, 다른 박스를 담을 수도 있음. 글만 따로 둘 때는 **텍스트 박스**
- **워크박스 안의 워크박스**: 끌어다 넣고 빼기, 둘러싸게 그리면 안으로 넣기, 바깥 박스를 옮기거나 지우면 안의 박스도 함께. Shift 를 누르고 옮기거나 만들면 들어갈 워크박스에 점 모눈종이가 보임
- **텍스트 꾸미기** (텍스트 박스와 워크박스): 가로 정렬(왼쪽 · 가운데 · 오른쪽), 세로 정렬(위 · 가운데 · 아래), 글꼴, 크기(6~200px), 굵게 · 기울임 · 밑줄 · 취소선, 글자 색(직접 고르기 가능), 줄 간격, 자간, 안쪽 여백
- **박스 형식**: 워크박스 · 텍스트 · 숫자 · 수식 · 체크(할 일) · 이미지. 크기 제한 없음
- **도형**: 사각형 · 둥근 사각형 · 원 · 마름모, 채우기/테두리 색
- **연결선**: 직선 · 곡선 · 꺾은선, 화살표(없음/한쪽/양쪽), 실선/점선, 라벨, 색, 두께. 박스를 옮기면 선이 따라옵니다
- **연결선 테두리**: 선이 나가는 테두리와 화살표가 붙는 테두리를 자동 · 왼쪽 · 위 · 아래 · 오른쪽 중에서 고름. 박스를 고르면 그 박스에서 나가는/들어오는 선 전체를 한 번에 바꿀 수 있음
- **계산**: 숫자 박스에 이름을 붙이고 수식 박스에서 `= 식비 + 교통비` 처럼 부르면 값이 바뀔 때마다 자동으로 다시 계산
- **편집**: 실행 취소/다시 실행, 복사/붙여넣기/복제, Alt+끌기 복사, 여러 개 선택, 정렬, 점에 맞추기, 맨 앞/맨 뒤
- **이미지**: 파일 고르기, 캔버스에 끌어다 놓기, 클립보드에서 붙여넣기
- **파일**: 자동 저장, 내 워크시트 모음, `.wsht` 파일 열기 / 다른 이름으로 저장 (이미지 포함 JSON), PNG / PDF 내보내기
- **템플릿**: 빈 캔버스, 가계부, 스토리 보드, 주간 플래너, 할 일 보드, 정보 노트, 계정 장부

## 수식 문법

```
= 식비 + 교통비 * 2              사칙연산과 괄호  + - * / ( )   (× ÷ 도 가능)
= SUM(식비, 교통비, 통신비)      함수 SUM AVG MIN MAX ROUND ABS
= ROUND(완료 / 전체 * 100, 1)    ROUND(값, 소수 자릿수)
= [11월 식비] / 4                공백이 있는 이름은 대괄호로
= 월요일.완료 / 월요일.전체      체크 박스의 완료 개수 / 전체 개수 / 남은 개수(.남음)
```

- 수식은 다른 수식 박스도 부를 수 있습니다 (`잔액 = 수입합계 - 지출합계`).
- 없는 이름, 같은 이름이 두 개, 순환 참조, 0으로 나누기는 박스에 오류로 표시됩니다.
- 숫자 안에 천 단위 쉼표(`1,000`)는 쓰지 않습니다. 쉼표는 함수 인자 구분에 씁니다.

## 조작법

| 동작 | 방법 |
| --- | --- |
| 확대 / 축소 | 마우스 휠, `Ctrl` + `+` / `-`, `Ctrl+0` (100%), `Ctrl+1` (화면 맞춤) |
| 화면 이동 | `Space` + 끌기 (휠 버튼 끌기, 이동 도구 `H` 도 가능) |
| 여러 개 선택 | 빈 곳에서 끌기(영역 선택), `Ctrl` + 클릭으로 하나씩 추가/빼기, `Ctrl+A` |
| 박스 만들기 | 왼쪽 도구를 고르고 캔버스를 클릭(기본 크기)하거나 끌기(원하는 크기). `Shift` 를 누르고 만들면 네 꼭짓점이 모두 점에 맞춰짐 |
| 내용 편집 | 박스 더블클릭 또는 `Enter`, 빈 곳을 더블클릭하면 새 텍스트 박스 |
| 이어 쓰기 | 쓰는 중에 `Tab` (오른쪽에 연결된 새 박스), `Ctrl+Enter` (아래에 새 박스) |
| 찾기 · 목차 | `Ctrl+F` — `Enter` 로 다음 결과, `Shift+Enter` 로 이전 결과 |
| 묶기 | `Ctrl+G` 워크박스로 묶기, `Ctrl+Shift+G` 풀기 |
| 속성 패널 | `Ctrl+.` |
| 워크박스에 넣기 | 워크박스 안으로 끌어다 놓기 (밖으로 끌어내면 빠짐), 박스들을 둘러싸게 워크박스 그리기 |
| 연결 | 선택한 박스 오른쪽의 파란 점을 다른 박스로 끌기, 또는 연결선 도구 `L` |
| 이동 | 끌기, `Shift` + 끌기는 왼쪽 위 꼭짓점을 점에 맞춰 이동, 방향키 1px (`Shift` 는 점 한 칸) |
| 복사 | `Alt` + 끌기 (이름이 겹치는 숫자/수식/체크 박스는 뒤에 숫자가 붙음) |
| 크기 조절 | 모서리 손잡이 끌기 (`Shift` 는 점에 맞춤, `Alt` 는 비율 유지) |

점은 24px 간격으로 고정이라 어떤 배율에서든 같은 점에 맞춰집니다. 보기 메뉴의 **항상 점에 맞추기** 를 켜면 `Shift` 없이도 맞춰집니다.

모든 조작법과 단축키는 프로그램 안의 **설정 → 마우스 조작 / 단축키** 에서도 볼 수 있습니다.

도구 단축키: `V` 선택 · `H` 이동 · `R` 사각형 · `O` 원 · `T` 텍스트 박스 · `S` 메모지 · `N` 숫자 · `F` 수식 · `C` 체크 · `I` 이미지 · `L` 연결선

## 개발

```bash
npm install
npm test              # 수식 · 박스 · 템플릿 · 상태 테스트
npm start             # 빌드 후 Electron 으로 실행
npm run dev           # 브라우저에서 화면만 보기 (http://localhost:5173)
npm run dist:win      # Windows 포터블 exe + zip  → release/
```

구성: Electron + React + TypeScript + Vite, 상태 관리는 zustand.

앱 아이콘은 `build/icon.svg`(큰 크기)와 `build/icon-small.svg`(16~32px)에서 만든 `build/icon.ico` 입니다. 리눅스에서 Windows 용으로 빌드할 때는 wine 이 없어서 electron-builder 가 실행 파일에 아이콘을 넣지 못하므로, `build/afterPack.cjs` 가 resedit 으로 `Worksheet.exe` 의 아이콘을 바꿉니다.

```
electron/main.cjs      창, 워크시트 모음, 파일 대화상자, 내보내기(PDF), 포터블 데이터 폴더
electron/preload.cjs   화면에 노출하는 API
src/fileOps.ts         자동 저장, 열기 / 만들기 / 이름 바꾸기
src/exporter.tsx       PNG / PDF 내보내기
src/formula.ts         수식 해석/계산
src/store.ts           문서 상태, 실행 취소 기록
src/components/        캔버스, 박스, 연결선, 도구 막대, 빠른 편집 막대, 찾기, 속성 패널, 시작 화면
src/styles/            화면 스타일 (base · shell · canvas · controls · home · settings)
src/templates.ts       시작 화면 템플릿
```
